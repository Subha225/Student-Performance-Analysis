# Student Performance Analysis

A beginner-friendly Python data analytics project using fictional sample marks.

## What it does
- Reads marks from a CSV file
- Calculates each student's average
- Finds the student with the highest average
- Calculates average marks for each subject
- Saves a bar chart as `subject_averages.png`

## Requirements
Python 3.9+, pandas, matplotlib.

## Run
```bash
pip install -r requirements.txt
python analysis.py
```

The dataset is fictional and intended only for practice.
